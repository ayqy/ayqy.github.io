Official support · Independent developer ayqy

Start with the tool, the action, and the result you expected.

MeowToolkit requires no developer account or demo login. Most issues can be isolated without sending private input or saved output.

OCR and document scan

  1. Confirm the selected image is clear and contains readable text.
  2. Try one image before a larger batch.
  3. Keep enough free storage for the exported PDF.
  4. If selection fails, review Photos access in iOS Settings.

The app receives only the photos you select and cannot edit or delete the library.

URL extraction and live data

  1. Check that the address begins with https:// or http://.
  2. Confirm the same page or named source is reachable in your region and network.
  3. Retry after a temporary unavailable or last-known result.

Some sites block automated extraction or vary by region; the app cannot bypass a site’s access rules.

Backup and continuity

  • A local backup includes recents and saved outputs, then merges with existing device data on import.
  • Purchases, focus sessions, live cache, and widget freshness are not copied by the backup.
  • Optional continuity uploads only after you connect a recovery space and choose Upload.
  • Store the recovery code securely. Do not place it in an initial support message.

Purchases and widgets

Use Restore Purchases in the app for an Apple ID that previously purchased access. Subscription management is provided by Apple. Widget updates follow iOS scheduling and may not refresh immediately; open the source tool once and allow the system time to update.

A useful first report

  • MeowToolkit version and build number
  • iOS or iPadOS version and device model
  • The tool and exact action immediately before the issue
  • The message or visible result, rewritten without private content
  • Whether the issue also happens with a small non-sensitive example

Do not include selected photos, document text, full extracted pages, saved outputs, purchase receipts, recovery codes, tokens, or private backup files unless a minimal item is specifically requested after the first reply.
