MeowMoment Support

Keep the facts; fix the path.

MeowMoment is designed to keep event data intact when a permission, network feature, purchase catalog, private backup, or system surface is unavailable.

Events and reminders

  1. Confirm the event is enabled and its saved time zone is correct.
  2. Open iOS Settings and verify notification permission for MeowMoment.
  3. Open the event again after changing recurrence, calendar, or reminder settings.
  4. If a recurring event looks unexpected, include the calendar type, saved date, and recurrence rule in your report.

Widgets and system surfaces

Open the app once after an update, then edit or re-add the widget if iOS still shows an old snapshot. Widget, Live Activity, Lock Screen, and Picture in Picture behavior depends on device, iOS version, permission, and system policy.

Private backup and purchases

Verify that the intended Apple Account is signed in. Restore Purchases synchronizes existing Apple transactions and does not start a new charge. A private iCloud backup is separate from purchase restoration.

Startup recovery

If the app shows a startup recovery screen, retry once without deleting or reinstalling the app. Record the non-sensitive reference code shown on screen. The recovery path does not replace the event library with an empty database.

Contact

Email MeowMoment Support

Include app version and build, iOS version, device model, the action immediately before the issue, the exact visible message, and any non-sensitive reference code. Do not include event titles, dates, notes, photos, backup contents, purchase receipts, account identifiers, or private files in your first message.
